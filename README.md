# orpc

End-to-end type-safe RPC for Nim.

oRPC is currently in its design phase; no framework implementation or public API is
available yet. See the [project brief](docs/project-brief.md), the
[v0.1 architecture proposal](docs/architecture-proposal.md), and the
[small-step roadmap](docs/roadmap.md). The proposed API and wire format remain subject
to maintainer review.
